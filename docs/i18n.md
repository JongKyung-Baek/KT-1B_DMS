# 다국어 운영 가이드

## 현재 지원 언어

- 한국어: `ko` (기본 언어)
- 영어: `en`

화면 문구는 `src/main/webapp/messages/feature*.properties`, 기존 공통 문구와
DB 기반 메뉴·그리드·폼·툴바·콤보 문구는 `DOCS_LANG`에서 관리한다. 사용자가
헤더 또는 로그인 화면에서 언어를 바꾸면 Spring Locale, 세션 사용자 언어,
메뉴와 콤보가 같은 언어로 함께 갱신된다.

## 인도네시아어 추가 절차

1. `LocaleUtil.SUPPORTED_LANGUAGES`에 `id`를 추가한다.
2. `feature_id.properties`를 만들고 한국어/영어 feature 번들과 같은 키를 모두
   번역한다.
3. `DOCS_LANG`에 `LANG_TYPE = 'id'`인 메뉴·그리드·폼·툴바·콤보 번역 행을
   추가한다.
4. 로그인과 헤더 언어 선택기에 `id` 항목을 추가한다.
5. `FeatureI18nContractTest`에 인도네시아어 번들 동등성 검사를 추가하고,
   실제 로그인 후 메뉴·대시보드·기술자료·ACL·이력 화면을 확인한다.

번들과 DB 번역이 준비되기 전에는 `id`를 지원 언어에 먼저 추가하지 않는다.
번역되지 않은 문구가 혼합되는 것을 막기 위해 미지원 브라우저 언어는 한국어로
안전하게 대체된다.
